# 지표 이상탐지 (조용한 감시)

매일 대시보드를 들여다볼 시간을 아껴준다. **문제일 때만** 핑.

## 1. 지표 읽기
- 지표 소스가 **claude.ai 커넥터**(Amplitude·GA·노션 지표표 등)로 연결돼 있으면 최근 값을 읽는다.
- 기준선(baseline)은 컨텍스트 문서의 노스스타/최근 지표, 또는 직전 값에서 잡는다.
- **미연결이면 지어내지 말고** "지표 소스 미연결 — 연결하거나 최근 숫자를 붙여주세요"로 끝낸다. **환각은 절대 금지**(지표 오보는 잘못된 의사결정으로 직결).

## 2. 이상 판정
- 급등/급락(예: 전주 대비 ±X%), 추세 꺾임, 가드레일 지표 악화, 데이터 끊김(수집 중단)을 본다.
- 임계 기준은 사용자와 합의된 값(없으면 "눈에 띄는 변화"를 보수적으로).

## 3. 출력 (이상 있을 때만 상세)
- **정상이면:** "특이사항 없음(주요 지표 정상 범위)" 한 줄로 끝. 길게 쓰지 않는다.
- **이상이면:**
  1. **무엇이 / 얼마나 / 언제부터** (숫자와 기간).
  2. **가능한 원인 가설** — 배포·캠페인·시즌성·외부요인 등. **근거 있는 것만, 추정은 "추정"으로.**
  3. **확인할 것** — 이 가설을 검증하려면 어디를 봐야 하나(세그먼트·퍼널 구간).
  4. **영향 & 시급도** — 지금 대응인지, 관찰인지.

## 4. 전송
이상 시에만 **개인본(private)** 알림:
```bash
python3 "$CLAUDE_PLUGIN_ROOT/scripts/post_slack.py" --to private --title "⚠️ 지표 알림" --file <초안> --dry-run
```

## 원칙
근거 없는 원인 단정 금지 · 상관과 인과 구분 · 왜 이상인지/왜 이 가설인지 설명 · 조용할 땐 정말 조용히.
