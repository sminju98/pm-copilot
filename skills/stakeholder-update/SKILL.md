# 이해관계자 업데이트 (청중별 3버전, 반자동)

같은 사실, 다른 언어. **초안까지만 — 전송은 사람이.**

## 1. 재료
```bash
cat "${PM_COPILOT_HOME:-$HOME/.pm-copilot}/data/context.md" 2>/dev/null
ls "${PM_COPILOT_HOME:-$HOME/.pm-copilot}/data/briefs/" 2>/dev/null   # 최근 진행상황
```
최근 진행/결정/지표(확인된 것)를 모은다. 부족하면 사용자에게 이번 기간 핵심 3가지를 묻는다.

## 2. 세 가지 버전 (요청한 것만 만들어도 됨)
1. **임원용 (Exec)** — 5줄 이내. 진척 요약 · **결정이 필요한 것** · **리스크/도움 요청** · 다음 마일스톤. 숫자와 결론 중심.
2. **개발/팀용 (Eng)** — 상세. 완료/진행/블로커 · 의존성 · 범위 변경 · 다음 스프린트. 실무 맥락.
3. **고객/외부용 (Customer)** — 가치와 일정 중심. 내부 사정·미확정 정보 제외. 과장 금지, 약속은 신중히.

각 버전 위에 **왜 이 톤인지** 한 줄 가이드를 남긴다(예: "임원은 결정·리스크만 본다").

## 3. 원칙 & 전송
- **같은 사실을 왜곡하지 않는다.** 청중별로 강조와 detail만 다르고, 나쁜 소식을 외부용에서 숨기지 않는다(불확실은 불확실로).
- **반자동:** 초안만. "검토 후 직접 보내세요." 슬랙 공유는 승인 후 `--dry-run` 확인하고 전송.
- 미확정 수치는 "확인 필요". 근거 없는 낙관 금지.

> `daily-brief`/`weekly-review` 결과를 이 스킬로 넘겨 보고본을 만들 수 있다.
