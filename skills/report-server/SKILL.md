# report-server — 요청할 때만 나간다

로컬은 자기 데이터만 본다. **"우리 ROAS 2.1이 좋은 건가"는 남의 분포를 알아야 답이 나온다.** 매체사는 자기 매체만 보고 대행사는 자기 고객만 본다. 그래서 서버가 필요하다.

## 실행 유형: [H] **전송은 사람이 요청할 때만.** 배경 루틴으로 올리지 않는다 — 동의를 받았어도 몰래 도는 업로드는 수확과 구분되지 않는다

## 0. 두 단계 — 먼저 보여주고 고르게 한다

```bash
pm-copilot report_server plan
```

| | 1단계 (기본) | 2단계 (선택) |
|---|---|---|
| 나가는 것 | 칸당 집계만 | **캠페인 원본** |
| 원본 위치 | 이 컴퓨터를 안 떠남 | 서버로 전송 |
| 받는 것 | 벤치마크 위치 | + 다채널 통합·이상 탐지·정밀 비교 |

**1단계만 써도 플러그인 전 기능이 동작한다.** 2단계는 리포트를 더 받는 선택이지 조건이 아니다.

## 1. 무엇이 나가는지 먼저 보여준다 (필수)

동의를 권하기 **전에** 실제 데이터를 보여준다. 설명만 하고 넘어가지 않는다.

```bash
pm-copilot report_server preview      # 나가는 데이터 전문
pm-copilot report_server consent      # 고지 전문
```

- **"괜찮으시죠?"라고 묻지 않는다.** 화면에 띄우고 사용자가 읽게 한다.
- 캠페인명·브랜드·계정ID·메모·오퍼·타깃 설명·메시지 원문은 애초에 빠진다. 마진·원가처럼 민감으로 판정된 값도 자동으로 빠진다.
- **2단계는 집계가 아니라 원본**이라는 사실을 흐리지 않는다. 흐리면 동의가 무효가 되고, 무효인 동의로 모은 데이터는 나중에 통째로 못 쓴다.

## 2. 동의 — 플래그 없이는 안 켜진다

```bash
pm-copilot report_server optin --agree
```

`--agree` 없이 부르면 고지문만 뜨고 켜지지 않는다. **한 번의 실수로 켜지지 않게 하려는 것**이다.

## 3. 요청 = 전송

```bash
pm-copilot report_server request
```

- **이때만 나간다.** 켜 뒀다고 배경에서 올라가지 않는다.
- 요청할 때마다 몇 건이 나가는지 다시 말해 준다.
- 2단계 동의가 없으면 아무것도 보내지 않고 그렇게 말한다.

## 4. 해지

```bash
pm-copilot report_server optout
```
즉시 1단계로 돌아가고 삭제 요청이 접수된다. **다만 통계에 이미 반영된 집계값은 개별 복원이 불가능**하다 — 이걸 미리 알린다.

## 5. 이해충돌을 숨기지 않는다

만든 곳(이미지팩토리)은 **퍼포먼스 마케팅 대행도 한다.** 2단계는 원본이 전송되므로 1단계와 달리 "볼 수 없는 구조"가 아니다.

- 이 사실을 **동의 전에 먼저** 말한다. 나중에 알려지면 그 한 줄로 신뢰가 무너진다.
- 부담스러워하면 **1단계를 권한다.** 2단계를 밀어붙이지 않는다.
- 사용자가 경쟁 관계를 걱정하면 그건 정당한 걱정이다. 반박하지 말고 1단계로 안내한다.

## 6. 하지 않는 것

- **배경에서 올리지 않는다.** 루틴·훅·스케줄에 전송을 넣지 않는다.
- **동의를 유도하지 않는다.** "다들 켜세요" 같은 말을 하지 않는다. 켜지 않아도 잃는 기능이 없다는 사실을 함께 말한다.
- **원본이라는 말을 피하지 않는다.** "연동", "동기화" 같은 말로 바꾸지 않는다.
- **표본이 부족하면 없다고 말한다.** 칸이 비었는데 그럴듯한 숫자를 만들지 않는다.
